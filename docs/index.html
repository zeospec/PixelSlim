Frequently Asked Questions

What makes PixelSlim faster than web compressors?

PixelSlim is a native macOS application built with Rust and Tauri v2. Unlike web-based tools that require uploading heavy images over the network and waiting for remote server queues, PixelSlim processes files directly on your Mac's hardware using multithreaded native codecs. It launches in under 250ms and optimizes images in milliseconds without network latency.

Which image formats does PixelSlim convert between?

PixelSlim accepts PNG, JPEG/JPG, WebP, AVIF, SVG, and GIF files, and converts them into modern WebP, AVIF, PNG, JPEG, and SVG formats. It also includes vectorization tracing for raster graphics and automated SVG minification.

Is PixelSlim 100% offline and private?

Yes. PixelSlim operates completely offline with zero telemetry, zero analytics, and zero cloud uploads. Your images, personal photos, and sensitive company assets never leave your computer. Furthermore, PixelSlim automatically strips sensitive EXIF metadata and GPS location coordinates from processed files.

Does it support Apple Silicon (M1/M2/M3/M4) and Intel Macs?

Yes. PixelSlim is distributed as a Universal DMG containing a native fat binary for both Apple Silicon (ARM64) and Intel (x86_64) architectures. It runs at peak native speed on all modern macOS machines running macOS 11.0 Big Sur or later.

How much does PixelSlim cost, and what is its license?

PixelSlim is 100% free and open-source software published under the MIT license.
